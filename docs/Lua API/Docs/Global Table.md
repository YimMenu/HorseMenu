# Global Table

## Methods

## `printf`

```lua
function printf(msg, ...) end
```

Prints a formatted message. Formatting works the same as [string.format](./string.md.format)

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| `msg` | `string` | Message. |
| `...` | `any` | Optional format arguments. |
